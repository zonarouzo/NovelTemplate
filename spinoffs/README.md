## 新しいスピンオフを作るには

Claude に次のように頼んでください。

> 新しいスピンオフを作りたい。タイトルは「〇〇」で、主人公は〇〇。

Claude がフォルダ（名前は半角英数字）と、その中の `drafts/`・`plots/`・`README.md` を作ります。
そのスピンオフだけの設定が必要な場合は、`settings/` フォルダも作ります。

## 各スピンオフフォルダの中身

- フォルダ直下：完成原稿（`.txt`）
- `drafts/`：第一稿・執筆途中の原稿（`.txt`）
- `plots/`：各話のプロット（`.md`）
- `settings/`：そのスピンオフだけの設定（必要な場合のみ）
- `README.md`：作品情報・話数一覧・進捗

共通の設定（キャラクター・世界観など）は、リポジトリのトップにある `settings/` を使います。
