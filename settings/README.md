# 共通設定資料（settings/）

このフォルダには、**本編とすべてのスピンオフに共通する設定** を置きます。
スピンオフだけで使う設定は、各スピンオフの `settings/` フォルダに置いてください。

## ファイル一覧

| ファイル | 内容 |
|---|---|
| [characters.md](characters.md) | キャラクター設定（名前・年齢・性格・口調・関係など） |
| [world.md](world.md) | 世界観設定（舞台・地理・社会・ルールなど） |
| [timeline.md](timeline.md) | 年表（作品内の出来事を時系列で整理） |
| [glossary.md](glossary.md) | 用語集（作中の固有名詞・造語と読み方） |
| [style_guide.md](style_guide.md) | 文体・表記ルール（原稿の書き方の決まり） |
| [style_samples/](style_samples/) | 文体サンプル（あなたの過去作など、文体の手本。読むだけの資料） |

## 資料を増やしたいとき

Claude に「〇〇の設定資料を作って」と頼めば、このフォルダに新しい `.md` ファイルを作ります。
新しく作ったら、上の表にも追加してもらいましょう。

例：`magic.md`（魔法のしくみ）、`places.md`（地名・施設の詳細）、`organizations.md`（組織・勢力）
