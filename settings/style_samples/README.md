# 文体サンプル（settings/style_samples/）

このフォルダには、**あなたの文体の手本になる文章**（過去に書いた作品の一部など）を `.txt` で置きます。
Claude は原稿を書くとき、ここにある文章の語り口・文の長さ・会話のテンポなどを参考にします。

## 置き方

いちばん簡単なのは、Claude Code の入力欄に文章を貼り付けて、次のように頼む方法です。

> これを文体サンプルとして保存してください。

## 大切なこと

- ここに置いた文章は **読むだけの資料** です。Claude は内容を変更・削除しません。
- 長い作品は、文体がよく表れている部分を抜き出して置けば十分です（例：1〜2話ぶん、数千字程度）。
- 文体の特徴をルールとして固めたいときは、「文体サンプルを分析して、文体ルール（style_guide.md）にまとめて」と頼んでください。
