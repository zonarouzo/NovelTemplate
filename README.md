# NovelTemplate — Claude と書く小説管理テンプレート

**Claude（Claude Pro）と GitHub を使って、小説の原稿・プロット・設定資料を管理するためのテンプレートです。**

- パソコンに何かをインストールする必要はありません。ブラウザだけで使えます。
- プログラミングや GitHub の知識は不要です。**Claude に日本語で話しかけるだけ** で、執筆・整理・保存ができます。
- 本編と、複数のスピンオフをまとめて管理できます。

> ⚠️ **現在は第1段階（試作版）です。**
> 作業内容を自動でメインの保存場所（`main`）に反映する仕組みや、詳しい使い方サイトは、次の段階で追加する予定です。
> 詳しくは「[現在の制限](#現在の制限)」をご覧ください。

---

## 必要なもの

- **Claude Pro** の契約（ブラウザ版 Claude Code を使います）
- **GitHub アカウント**（無料）
- パソコンのブラウザ（Chrome、Edge、Safari など）

## はじめかた（概要）

1. このテンプレートから、**自分専用のリポジトリ（作品の保管場所）** を作ります。
   - このページ上部の「**Use this template**」→「**Create a new repository**」を押します。
   - 公開設定は必ず **Private（非公開）** を選んでください。あなたの原稿が他人に見えなくなります。
2. ブラウザで [Claude Code（claude.ai/code）](https://claude.ai/code) を開き、GitHub と連携します。
3. 作った自分のリポジトリを選んで、Claude に話しかけます。
4. 最初に、次のように頼んでください。

   > サンプルを消して、私の作品用に初期設定をしてください。

   Claude が、削除してよいファイルを確認しながら、あなたの作品用の準備をしてくれます。

※ 画面つきの詳しい手順は、次の段階で用意する予定です。

## Claude への頼み方の例

普段の言葉で大丈夫です。

| やりたいこと | 話しかけ方の例 |
|---|---|
| プロットを作る | 「本編の第4話のプロットを作って。ナギが星図の謎に気づく話にしたい」 |
| 原稿を書く | 「第4話のプロットをもとに、第一稿を書いて」 |
| 原稿を直す | 「第4話の第一稿、後半の会話をもっと短くして」 |
| 完成させる | 「第4話を完成原稿にして」 |
| 完成原稿を直す | 「完成原稿の第1話の誤字を直して」 |
| 設定を追加する | 「新しいキャラクターを追加したい。名前は〇〇で…」 |
| 矛盾を調べる | 「本編とスピンオフの設定に矛盾がないか確認して」 |
| スピンオフを作る | 「新しいスピンオフを作りたい。タイトルは〇〇」 |
| 進み具合を知る | 「本編の進み具合を教えて」 |

## フォルダの構成

```
（あなたのリポジトリ）
├── README.md          … この説明書
├── CLAUDE.md          … Claude が守るルール（ふだんは触らなくてOK）
├── settings/          … 全作品に共通する設定資料
│   ├── characters.md  …   キャラクター
│   ├── world.md       …   世界観
│   ├── timeline.md    …   年表
│   ├── glossary.md    …   用語集
│   ├── style_guide.md …   文体・表記のルール
│   └── style_samples/ …   文体の手本（あなたの過去作など）
├── novels/            … 本編
│   ├── README.md      …   作品情報・話数一覧・進み具合
│   ├── episode01.txt  …   完成原稿
│   ├── drafts/        …   第一稿・書きかけの原稿
│   └── plots/         …   各話のプロット
└── spinoffs/          … スピンオフ（1作品＝1フォルダ）
    └── sample_spinoff/
        ├── README.md  …   作品情報・話数一覧・進み具合
        ├── drafts/    …   第一稿・書きかけの原稿
        ├── plots/     …   各話のプロット
        └── settings/  …   このスピンオフだけの設定（必要なときだけ）
```

### 原稿の流れ

```
プロット（plots/episode01.md）
   ↓ 「第1話を書いて」
第一稿（drafts/episode01.txt）
   ↓ 「第1話を完成原稿にして」 ← あなたがはっきり指示したときだけ
完成原稿（episode01.txt）
```

### すでに書いた原稿を取り込むには

書いてある原稿を Claude Code の入力欄に貼り付けて、「これは本編の第1話の完成原稿です。そのまま保存してください」のように頼んでください。
本文は直さずにそのまま保存されます。取り込んだあと「取り込んだ原稿から設定資料とプロットを作って」と頼むと、案を作ってくれます。

### 自分の文体で書いてもらうには

過去に書いた作品の一部を Claude Code の入力欄に貼り付けて、「これを文体サンプルとして保存して」と頼んでください。
`settings/style_samples/` に保存され、Claude は執筆のたびにそれを参考にします。
「文体サンプルを分析して、文体ルールにまとめて」と頼むと、特徴を `style_guide.md` に整理してくれます。

## Claude が守るルール

Claude は `CLAUDE.md` に書かれたルールに従って作業します。主なルールは次のとおりです。

- 📄 **小説本文は `.txt`（テキストファイル）** で保存します。見出し記号などの余計な飾りは入れません。
- 📝 **設定資料・プロットは `.md`** で保存します。
- 🔒 **完成原稿は、あなたが指示しない限り変更しません。**
- 🗑️ **原稿を削除するときは、必ずあなたに許可を求めます。**
- ✅ **第一稿を完成原稿にするのは、あなたが指示したときだけです。**
- ❓ **共通設定とスピンオフの設定が食い違っていたら、あなたに確認します。**
- 📚 **書く前に、これまでの原稿や設定を読んでから執筆します。**
- 💬 **作業が終わったら、何をしたかをわかりやすい日本語で報告します。**

## サンプルについて

このテンプレートには、使い方の例として **架空の作品『星読みの灯台』** と、そのスピンオフ『灯台守見習いの日誌』が入っています。
サンプルのファイルには「【サンプル】」と書かれています（原稿の `.txt` を除く）。

使い始めるときは、Claude に「サンプルを消して初期設定して」と頼めば、まとめて整理してくれます。
自分で消す必要はありません。

## 現在の制限

この第1段階では、次の機能はまだありません。

- **作業内容をメインの保存場所（`main`）へ自動で反映する仕組み**
  ブラウザ版 Claude Code は、作業内容を `main` とは別の「作業用の保存場所（ブランチ）」に保存することがあります。
  その場合、GitHub 上で「プルリクエスト」を作って `main` に取り込む操作が必要になります。
  これを自動化する仕組みは次の段階で追加する予定です。
- **画面つきの詳しい使い方サイト（HowTo）**
- **高度な原稿管理機能**（文字数の集計、一括チェックなど）
